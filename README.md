# Bike-Sales-Data-Dashboard-in-Excel
This project demonstrates end-to-end data analysis using Microsoft Excel. The objective was to transform raw customer data into an interactive dashboard to uncover insights regarding bike purchases.
# Data Cleaning
Removed duplicate records, standardized text values (e.g., converting 'M/S' to 'Married/Single' and 'M/F' to 'Male/Female' using Find & Replace), and categorized age groups using nested IF statements to create meaningful analytical groups.
# Data Analysis
Created multiple Pivot Tables to calculate metrics such as average income and purchase counts segmented by gender, commute distance, and age brackets.
# Visualization
Built an interactive dashboard featuring bar and line charts to visualize purchase trends and customer behavior.
# Interactivity
Implemented Slicers for dynamic filtering (Marital Status, Region, and Education) to enable demographic-based data exploration.
